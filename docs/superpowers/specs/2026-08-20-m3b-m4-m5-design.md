# M3b + M4 + M5 — Assemble, QC/repair, observability

**Date:** 2026-08-20  
**Status:** Implemented  
**Scope:** Wire the remaining PRD stages onto the M3a graph. Out of scope: dialogue, non-40s, voiceover, editing UI, >1080p.

## Graph (flags on)

```
plan_story → lock_continuity_bible
  → generate_shot_n → chain_frame_n → qc_score_n
       --pass--> next n or assemble
       --fail, repairs<2--> repair_shot_n → chain_frame_n → qc_score_n
       --fail, repairs==2--> flag_degraded_n → next n or assemble
  → assemble → deliver → END (DELIVERED or PARTIAL)
```

Feature flags (each new behaviour): `FEATURE_QC_REPAIR`, `FEATURE_ASSEMBLE_DELIVER`. Both no-op unless `FEATURE_SHOT_GENERATION` is on. Resume evaluates current flags.

## Status mapping

| Condition | Harness | API |
|---|---|---|
| Bible only (shots flag off) | SUCCESS | BIBLE_LOCKED |
| 4 shots, assemble off | SUCCESS | SHOTS_READY |
| Assemble+deliver, no degraded | SUCCESS | DELIVERED |
| ≥1 shot, any degraded / incomplete stitch | PARTIAL | PARTIAL |
| Same failure signature twice | FAILED_NO_PROGRESS | FAILED_NO_PROGRESS |

## M3b

- `assemble`: ffmpeg concat of resolved clips (success or flagged-degraded). Zero clips → no silent success.
- `deliver`: HMAC presigned URLs for assembled MP4, per-shot clips, thumbnail. Local filesystem is the v1 store; `STORAGE_BUCKET` is reserved and unused until a cloud adapter exists (no fake S3).
- `GET /jobs/{id}/artifacts/{name}` serves bytes after verifying the signature.

## M4

- `qc_score` via `vision-default`, schema `qc_score`. Pass iff score ≥ 0.75 (code owns the threshold).
- Repair cap = 2 per shot. Exhaustion → `flag_degraded`, keep best-scoring clip, continue. Never drop the shot.
- Budget trip mid-loop with ≥1 clip still runs assemble/deliver when that flag is on (`PARTIAL` stitch).

## M5

- JSON logs carry `trace_id`. Langfuse HTTP tracer when keys are set; no-op otherwise. Prompts: Langfuse registry first, local templates fallback.
- Gateway rungs 2–4: same-alias fallback from config only; per-alias circuit (5 failures / 30s, half-open probe); degrade to last cached JSON for that schema when the circuit is open.
- CI: pytest eval/cost gates vs `tests/eval/baselines.json` (>3% eval drop or >20% cost rise fails).
